# 擴充功能需求單模板

複製下面的區塊填寫。**不必全部填完**——填得出來的先填，空白處會被當成待確認事項回問你。

只給一份現成程式碼、一句「照這個邏輯做成模組」也可以：這種情況下，
下面「一定要你決定的六件事」仍會逐項跟你確認，因為舊程式裡的行為不見得是刻意的定義。

---

## 一定要你決定的六件事

這六項會直接改變交通結果的意義，沒有預設答案：

| # | 問題 | 為什麼不能猜 |
| --- | --- | --- |
| 1 | 計數對象是**每台車**還是**每個樣本**／**每個事件**？分母是誰？ | 同一份資料可以算出差好幾倍的數字 |
| 2 | 比較用 `>` 還是 `>=`？區間左閉右開還是兩端都含？ | 剛好等於門檻的資料算不算，結果會差 |
| 3 | 同值時取誰（最早時間／最大值／全部）？ | 決定輸出是一列還是多列 |
| 4 | 先切時段再計算，還是先計算再篩選？ | 兩者答案不同，且都合理 |
| 5 | 輸入是否已平滑／已換算 m/s／已切 ROI？誰負責？ | 決定這個功能的邊界在哪 |
| 6 | 缺值、負值、離群值要**拋錯**還是**排除**？排除的話怎麼回報數量與原因？ | 默默丟資料會讓分母說不清楚 |

另外每次都會問一件事：這個功能在 `docs/catalog.md` 的**負責人**要填誰。

## 填寫範例

已完成的 `speed.speed_distribution` 就是照這份格式填出來的，
成品見 [`worksheets/speed.speed_distribution.md`](worksheets/speed.speed_distribution.md)。
當時的關鍵決定與理由：

| 決定 | 選了什麼 | 理由 |
| --- | --- | --- |
| 計數對象 | 每台車 | 停留久的車若按樣本計數會被重複計，塞車時分布會整個歪掉 |
| 區間開閉 | `[lower, upper)`，最後一箱含右端點 | 不讓最大值落在所有箱子之外 |
| 範圍外的車 | 不進分箱，但仍計入整體統計，另外計數 | 舊程式先過濾再統計，母體會靜悄悄縮小 |
| 移動門檻 | 預設不過濾，要用就明講 | 舊程式固定砍掉 7.2 km/h 以下，換個場景就不適用 |
| 單車標準差 | 回 `None` | 舊程式回 `0.0`，會被讀成「速度很一致」 |
| 車種分組 | 不做，由呼叫端逐組呼叫 | 車種對照表是專案設定，不是交通定義 |
