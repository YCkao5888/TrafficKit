# 工作單

每個功能一份工作單，內容是**完整的交通契約**：輸入欄位、參數、判定規則、
統計口徑、品質政策、手算範例，以及實際跑出來的驗證紀錄。

API reference 回答「怎麼呼叫」，工作單回答「為什麼這樣算、算出來的數字
代表什麼、還有什麼沒驗證」。功能升到「正式」之前，工作單的
「舊程式差異與已知限制」一節特別值得先看。

每份工作單的「驗證環境與版本」是**當下的快照**，記錄那次交付實際驗過什麼。
新增功能時只填自己那一份，不必回頭修改舊功能工作單裡的測試數量或日期。
